# V01 Colour contrast

Text has a contrast of 4.5:1 with what is behind it, the edges and marks
that show a control and its state 3:1 with what is next to them, and a
state is never shown by colour alone.

Code: [`lib/techniques/v01_colour_contrast/examples.dart`](../../lib/techniques/v01_colour_contrast/examples.dart).
Spec: [`docs/specs/V01-colour-contrast.md`](../specs/V01-colour-contrast.md).
In the app: `/t/V01`, and each example at `/t/V01/<slug>`.

Platforms: Android, iOS, and the web apply. Every good example is
Flutter's own widgets through their documented parameters; none is a
custom solution
([custom-solutions.md](../custom-solutions.md#v01-colour-contrast)).
Every contrast here was measured from rendered pixels, in light and dark
mode, on every layer: the widget tests, Chromium, the Android emulator,
and the iOS simulator. What Flutter's defaults give, and where they fall
short, is recorded, not built:

- Cupertino's field has a placeholder of 1.72:1 (light) and 2.23:1 (dark)
  ([FL-510](../flutter-limitations.md#fl-510)) and an edge of 1.25:1
  ([FL-511](../flutter-limitations.md#fl-511)); `good-cupertino` gives
  both a stronger grey with the field's own parameters.
- A `CupertinoButton` fades to 0.4 opacity while it is pressed, and a
  filled one's text to 1.88:1 ([FL-514](../flutter-limitations.md#fl-514));
  `good-cupertino` sets `pressedOpacity: 0.9`, a value of the engineer's,
  for the principal to decide on.
- A `GridTileBar` has no background unless it is given one
  ([FL-512](../flutter-limitations.md#fl-512)).
- A selected `ListTile` is shown by colour alone
  ([FL-513](../flutter-limitations.md#fl-513)).
- On the web, with a mouse button held on a control, three of the good
  examples' texts fall to 4.19:1 to 4.25:1
  ([FL-515](../flutter-limitations.md#fl-515)). No fix was tried; whether
  this makes the web a limitation for that state is the principal's
  decision (the spec, section 5).

## Why it matters

People with low vision, and anyone in sunlight or on a dim screen, read
text and find controls by the difference between their colours and what
is behind them. Faint text, a placeholder in a pale grey, or a caption on a
pale part of a photo cannot be read; a field whose edge is too faint
cannot be found. People who cannot tell some colours apart cannot see a
choice that is shown only by a change of colour.

## WCAG 2.2

- [1.4.3 Contrast (Minimum)](https://www.w3.org/TR/WCAG22/#contrast-minimum): text 4.5:1, or 3:1 if large (no text here is). It covers placeholder text and every state of a control; a disabled control's text is excepted.
- [1.4.11 Non-text Contrast](https://www.w3.org/TR/WCAG22/#non-text-contrast): what shows a control and its state, 3:1 against what is next to it: a field's edge, a checkbox's box and mark, a radio button's ring and dot. A button with text needs no boundary.
- [1.4.1 Use of Color](https://www.w3.org/TR/WCAG22/#use-of-color): a choice shown by colour alone fails, unless the colours differ in lightness by 3:1.

The criteria as written, with their exceptions, are in
[Understanding 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html),
[Understanding 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html),
and [Understanding 1.4.1](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html);
text over a picture without enough contrast is failure
[F83](https://www.w3.org/WAI/WCAG22/Techniques/failures/F83).
The source is the iOS reference repository's
[Contrast](https://github.com/cvs-health/ios-swiftui-accessibility-techniques/blob/main/iOSswiftUIa11yTechniques/Documentation/Contrast.md)
(4.5:1 and 3:1, semantic colours that adapt to dark mode, a field's
border), with the Understanding documents for placeholders, states, and
colour alone.

```dart
/// A picture that is pale on the left and dark on the right, as a photo of
/// a harbour under a pale sky might be. It is drawn as a gradient so that
/// every layer measures the same pixels.
class Picture extends StatelessWidget {
  const Picture({super.key});

  @override
  Widget build(BuildContext context) {
    return const DecoratedBox(
      decoration: BoxDecoration(
        gradient: LinearGradient(
          colors: [Color(0xFFC5CAE9), Color(0xFF1A237E)],
        ),
      ),
    );
  }
}

/// A picture with a caption, the caption a [GridTileBar] in the tile's
/// footer. [captionBackground] is the bar's `backgroundColor`.
class CaptionedPicture extends StatelessWidget {
  const CaptionedPicture({super.key, this.captionBackground});

  final Color? captionBackground;

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      height: 120,
      child: GridTile(
        footer: GridTileBar(
          backgroundColor: captionBackground,
          title: const Text('Harbour'),
        ),
        child: const Picture(),
      ),
    );
  }
}

/// The calendar views a person can choose between.
enum CalendarView { day, week, month }

extension CalendarViewName on CalendarView {
  String get title => switch (this) {
    CalendarView.day => 'Day',
    CalendarView.week => 'Week',
    CalendarView.month => 'Month',
  };
}

/// A Cupertino field's placeholder and edge colour: `systemGrey`'s
/// high-contrast colours, 5.2:1 on the field's white in light mode and
/// 9.5:1 on its black in dark mode (as measured, the spec, section 7).
const fieldGrey = CupertinoDynamicColor.withBrightness(
  color: Color(0xFF6C6C70),
  darkColor: Color(0xFFAEAEB2),
);

/// The edge `good-cupertino` and `bad-cupertino-placeholder` give their
/// field in place of the default hairline (FL-511).
const fieldDecoration = BoxDecoration(
  color: CupertinoColors.systemBackground,
  border: Border.fromBorderSide(BorderSide(color: fieldGrey)),
  borderRadius: BorderRadius.all(Radius.circular(5)),
);

/// A Cupertino email field with a visible label above it, which also names
/// it (a Cupertino field has no label of its own, FL-016).
class CupertinoEmailField extends StatelessWidget {
  const CupertinoEmailField({
    super.key,
    required this.id,
    this.placeholderStyle,
  });

  final String id;

  /// The placeholder's style; null keeps the default.
  final TextStyle? placeholderStyle;

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        const ExcludeSemantics(child: Text('Email')),
        const SizedBox(height: 4),
        TestId(
          id,
          child: Semantics(
            label: 'Email',
            child: placeholderStyle == null
                ? const CupertinoTextField(
                    placeholder: 'Required',
                    decoration: fieldDecoration,
                  )
                : CupertinoTextField(
                    placeholder: 'Required',
                    placeholderStyle: placeholderStyle!,
                    decoration: fieldDecoration,
                  ),
          ),
        ),
      ],
    );
  }
}
```

### `good-material`

```dart
/// A short form at the theme's defaults: body text in `onSurface`, a field
/// with its label floating so that its hint shows at rest, a checkbox, and
/// a button. Every text is 4.5:1 or more and every edge that marks a
/// control 3:1 or more, light and dark. The button is an `OutlinedButton`:
/// a `FilledButton`'s text drops under 4.5:1 with focus and a hover in
/// light mode (FL-253).
class GoodMaterial extends StatefulWidget {
  const GoodMaterial({super.key});

  @override
  State<GoodMaterial> createState() => _GoodMaterialState();
}

class _GoodMaterialState extends State<GoodMaterial> {
  var _updates = false;

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.stretch,
      children: [
        const Text('We reply within two days.'),
        const SizedBox(height: 16),
        const TestId(
          'v01-good-material-email',
          child: TextField(
            decoration: InputDecoration(
              labelText: 'Email',
              hintText: 'Required',
              hintMaxLines: 2,
              floatingLabelBehavior: FloatingLabelBehavior.always,
              border: OutlineInputBorder(),
            ),
          ),
        ),
        TestId(
          'v01-good-material-updates',
          child: CheckboxListTile(
            title: const Text('Send me updates'),
            value: _updates,
            onChanged: (v) => setState(() => _updates = v ?? false),
          ),
        ),
        Align(
          alignment: Alignment.centerLeft,
          child: TestId(
            'v01-good-material-send',
            child: OutlinedButton(onPressed: () {}, child: const Text('Send')),
          ),
        ),
      ],
    );
  }
}
```

### `good-cupertino`

```dart
/// Cupertino's field with its placeholder and its edge in `systemGrey`'s
/// high-contrast colours, through `placeholderStyle` and `decoration`. The
/// defaults are under the thresholds (FL-510, FL-511). The button is
/// `CupertinoButton.filled`, whose colour here is the app theme's primary,
/// with a `pressedOpacity` that keeps its text 4.5:1 while it is held.
class GoodCupertino extends StatelessWidget {
  const GoodCupertino({super.key});

  @override
  Widget build(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        const CupertinoEmailField(
          id: 'v01-good-cupertino-email',
          placeholderStyle: TextStyle(color: fieldGrey),
        ),
        const SizedBox(height: 16),
        TestId(
          'v01-good-cupertino-send',
          child: CupertinoButton.filled(
            // While pressed the default fades the button to 0.4 opacity,
            // and its text to under 4.5:1 on its fill (FL-514).
            pressedOpacity: 0.9,
            onPressed: () {},
            child: const Text('Send'),
          ),
        ),
      ],
    );
  }
}
```

### `good-selection`

```dart
/// The same choice as `bad-colour-only`, as `RadioListTile`s in a
/// `RadioGroup`: the chosen one's radio button is a filled ring and the
/// others' are empty, so the choice is shown by a shape as well as by
/// colour.
class GoodSelection extends StatefulWidget {
  const GoodSelection({super.key});

  @override
  State<GoodSelection> createState() => _GoodSelectionState();
}

class _GoodSelectionState extends State<GoodSelection> {
  var _view = CalendarView.week;

  @override
  Widget build(BuildContext context) {
    return RadioGroup<CalendarView>(
      groupValue: _view,
      onChanged: (v) => setState(() => _view = v ?? _view),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.stretch,
        children: [
          const Text('Calendar view'),
          for (final v in CalendarView.values)
            TestId(
              'v01-good-selection-${v.name}',
              child: RadioListTile<CalendarView>(
                value: v,
                title: Text(v.title),
              ),
            ),
        ],
      ),
    );
  }
}
```

## What each platform exposes

Measured on Flutter 3.47.5: the widget tests, Chromium in Playwright, the
Android 17 emulator, and the iOS 27.0 simulator. Flutter draws the same
colours on every platform; the figures in the tables above hold on every
layer to within 0.1 (the spec, section 7). A colour is not spoken.

| | Web | Android | iOS |
| --- | --- | --- | --- |
| Dark mode, as the tests set it | `prefers-color-scheme: dark` | `cmd uimode night yes` | `XCUIDevice.appearance` |
| States measured | rest, focus, hover, both, a mouse button held | rest, focus from a registered keyboard, a finger held 180 to 300 ms | rest, focus by Tab |
| The Cupertino field's name | "Email Required": the placeholder joins the label | "Email Required" | `Email\nRequired` |
| The Material field's hint "Required" | not in the name | not spoken | not spoken |
| `bad-colour-only`'s chosen tile | a button with `aria-current="true"`, and no selected state in Chromium's tree | "selected. / Week / Button" | "selected Week Button" |

## Flutter limitations

Found on Flutter 3.47.5. Full detail is in the
[limitations log](../flutter-limitations.md).

- [FL-510](../flutter-limitations.md#fl-510): a `CupertinoTextField`'s default placeholder is under 4.5:1.
- [FL-511](../flutter-limitations.md#fl-511): a `CupertinoTextField`'s default edge is under 3:1.
- [FL-512](../flutter-limitations.md#fl-512): `GridTileBar` has no background by default.
- [FL-513](../flutter-limitations.md#fl-513): a selected `ListTile`, and `ToggleButtons`' chosen button, are shown by colour alone.
- [FL-514](../flutter-limitations.md#fl-514): a pressed `CupertinoButton` fades its text under 4.5:1.
- [FL-515](../flutter-limitations.md#fl-515): on the web a mouse button held lowers some Material texts under 4.5:1.
- [FL-516](../flutter-limitations.md#fl-516): a `CupertinoSwitch` is under 3:1 in light mode (probe only).
- [FL-517](../flutter-limitations.md#fl-517): `secondaryLabel` and `tertiaryLabel` are under 4.5:1 as text in light mode (probe only).
- [FL-242](../flutter-limitations.md#fl-242), [FL-253](../flutter-limitations.md#fl-253), [FL-441](../flutter-limitations.md#fl-441): extended with V01's measurements.
